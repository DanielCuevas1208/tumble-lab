# Changelog

All notable changes to this project are listed here. This format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.2.0] - 2026-08-03

### Added

- Busted test suite for the engine and tools.
- LOVE interactive sandbox with scenes and body dropping.
- Headless snapshot renderer for scenes.
- CI workflow with lint, format, and test jobs.
- README and roadmap documentation.
- MIT license and repository metadata.

### Changed

- Reformatted all Lua sources to match the project style.
- Fixed lint warnings in the world and runner modules.
- Fixed the runner scenario list ordering.

## [0.1.0] - 2026

### Added

- Core engine with bodies, shapes, and contacts.
- Sequential impulse solver with warm starting.
- Deterministic random generator.
- Scenario builders.
- Headless runner with record and replay.
- Recording and replay format.
